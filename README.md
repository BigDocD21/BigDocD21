О проекте

Ручное тестирование сервиса аренды самокатов «Самокат». Проверялись:

-веб-лендинг — страницы «Главная», «Для кого самокат», «Про аренду», «Статус заказа»;
-мобильное приложение курьера** — уведомления о сроке заказа, офлайн-сценарии;
-API — ручка отмены заказа `PUT /api/v1/orders/cancel` (сверка кодов ответа сервера со спецификацией).

Цели работы

1. Проверить вёрстку и бизнес-логику страницы «Статус заказа»: отображение данных, четыре статуса заказа, отмена заказа.
2. Проверить валидацию полей форм методами тест-дизайна: классы эквивалентности и граничные значения.
3. Проверить поведение мобильного приложения курьера в нестандартных состояниях: фоновый режим, авиарежим, заблокированный экран, отсутствие интернета.
4. Протестировать API отмены заказа на соответствие спецификации.
5. Локализовать и оформить найденные дефекты, выполнить приоритизацию.

Состав работы:
-Чек-лист страницы «Статус заказа» (вёрстка + логика) 122 проверки, кроссбраузерно Вкладка «Задание 1 чек-лист»
-Классы эквивалентности и граничные значения 9 полей веб-форм Вкладка «Задание 1 данные валидации»
-Тест-кейсы мобильного приложения курьера 20 кейсов Вкладка «Задание 2 тест-кейсы»
-Баг-репорты 45 (BG-1 … BG-45) Вкладка «Баг-репорты» 
-Дефекты, найденные вне тестовой документации 11 (BG-34 … BG-44) Вкладка «Баги вне тестовой документации»

Инструменты

- Яндекс.Браузер 26.8.3.1002 (1920×1080), Chrome 153.0.8010.53 (1280×720) — кроссбраузерное тестирование веб-лендинга
- Android Studio (эмулятор, Android 9.0) — тестирование мобильного приложения курьера
- Postman — проверка API (ручка отмены заказа)
- Google Sheets — тест-документация: чек-листы, классы эквивалентности, тест-кейсы, баг-репорты

 Ключевые находки

- BG-33 (критический) — после отмены заказа он удаляется из системы, но остаётся доступным для отслеживания: нарушена бизнес-логика удаления.
- BG-45 (критический, API) — код ответа сервера при отмене заказа не соответствует спецификации (`PUT /api/v1/orders/cancel`), дефект обнаружен через Postman.
- BG-32 (блокирующий) — дефект блокирует 9 проверок кнопки «Отменить заказ»; проверки корректно помечены статусом BLOCKED.
- Группа дефектов валидации (BG-1, BG-2, BG-7…BG-10, BG-13…BG-16, BG-18, BG-19) — поля пропускают невалидные данные (спецсимволы, некорректные длины, даты в прошлом) или отклоняют валидные (дефис в имени).
- Дефекты вёрстки (BG-20…BG-25, BG-28…BG-30) — расхождения расположения, цветов и текстов с макетом.
- 11 дефектов интерфейса (BG-34…BG-44) обнаружены сверх тестовой документации — разведочное тестирование страниц «Главная», «Для кого самокат», «Про аренду».
